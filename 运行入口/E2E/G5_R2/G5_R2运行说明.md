# G5-R2手动运行

## 启动

在PyCharm选择解释器 D:\Software\anaconda3\envs\PyTorch\python.exe，直接运行同目录的 [G5_R2一键运行.py](G5_R2一键运行.py)，无需参数。入口使用自身路径定位项目，不依赖PyCharm工作目录。

已按用户要求增加基础轮数，总运行预算上限为12小时（含准备、训练、评价和收尾）。启动时核对当前合同与准备报告，不手改报告或跳过预算检查。

入口依次执行：输入与代码身份检查 → 两seed的C0/C1/C2配对训练 → 冻结最佳权重 → 六轨开发集比较 → 统计、案例图与完整性报告。原G5/G5-R1结果只读，不生成新DPD，不访问test。

## 进度与耗时

- 训练进度条每20秒最多更新一次，显示seed、组别、epoch、batch、已用时间及当前阶段预计剩余时间。
- 建议在PyCharm运行配置中启用“Emulate terminal in output console / 在输出控制台中模拟终端”，使进度条原行更新；不支持时也只有低频输出。
- 每个epoch结束保留一行训练/验证耗时及best信息。磁盘日志不累计进度条刷新行，实时状态另写 run/progress.json。
- 基础20轮；若best在第18或20轮且第16至20轮联合Recall继续改善，同seed三组一起延长到24轮。六轨正式训练及比较由本入口执行，Codex交付时尚未启动。

## 中断与继续

每个完整epoch保存模型、关联头、优化器、随机数状态和样本排列生成器状态；保存回读成功后才更新完成标记。中断后重新运行同一入口，从最后完整epoch继续，未完成epoch从头重算。失败尝试和日志保留。

预算从首次正式启动计时，并计入准备耗时；暂停不会重置截止时间。预算超限、输入异常或代码身份变化需要先处理，不要删除结果目录重新计时。重复进程会被拒绝，全部完成后再次点击只提示结果位置。

仅检查而不训练时，在运行参数中填写 --check-only。

## 输出与回读

全部新产物位于：

    F:\SourceCount_DPD_E2E\outputs_e2e\unified\e2e_g5_r2\20260921_approved\

- contract.json：本轮配置、源文件身份及原G5最终阶段学习率。
- preparation_report.json：短时工程测试与耗时预测；不是正式性能结果。
- engineering/：短测、恢复验证及保留的旧准备合同。
- run/training/：六轨历史、完整epoch恢复点、选定权重。
- run/training_report.json：轮数、步数、选模与预算未解析标记。
- run/evaluation/：正式比较及案例图。
- run/logs/attempt_*/：每次启动的精简日志和退出回执；失败时含 failure_report.json。

完成后向Codex提供以下四个文件即可开始结果回读：

1. run/evaluation/运行摘要.md
2. run/evaluation/comparison_report.json
3. run/evaluation/final_audit_report.json
4. run/training_report.json

逐样本JSONL通过每轨 run/evaluation/<seed>_<arm>/complete.json 追溯，图在 run/evaluation/figures/。若报错，提供本次 run/logs/attempt_*/failure_report.json 和 run.log；入口打印的错误应原样保留。
